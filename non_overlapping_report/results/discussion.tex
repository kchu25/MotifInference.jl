\paragraph{Measure the way discovery measures.} The single most important lesson of this report
is methodological. On the raw support (every nonzero activation), the operator looks weak: with
$50$ filters, a typical active position is shared by twenty-plus of them, and sharpening the
softmax barely dents it. But motif finding never touches those weak activations --- it thresholds
by magnitude first and acts only on the strong ones. Once the metric matches that threshold, the
same operator looks effective: the strong activations are already fairly separated with the
operator off, and softmax $\alpha\approx20$ takes them to four-fifths one-per-position for almost
nothing. The lesson generalizes: an interpretability operator should be judged on the signal the
downstream method consumes, not on every floating-point nonzero.

\paragraph{The soft knob is the practical tool.} Softmax strength $\alpha$ is a differentiable dial
from a soft blend toward a per-position winner-take-all. On the strong activations it is potent and
cheap: by $\alpha\approx20$, occupancy is $1.2$ and exclusivity $0.83$ at essentially no accuracy
cost. A narrower filter bank helps too. We also implemented a hard cross-filter winner-take-all
(a Gumbel-softmax variant, one filter per position at inference); it reaches the ideal outright but
costs more accuracy and breaks motif discovery (below), and since $\alpha\approx20$ already captures
almost all the benefit, we removed it. What remains in the code is the clean, soft operator with a
single strength knob.

\paragraph{Discovery already enforces the non-overlap it needs.} An important piece of context
sharpens what the operator is (and is not) for. The co-occurrence counter (EpicHyperSketch,
v0.0.8) never counts overlapping motif groups: for a candidate it computes the gap between
consecutive filters, $\text{position}_2 - \text{position}_1 - \texttt{filter\_len}$, and discards
the group when that gap is negative --- the filter footprints (width
$\texttt{filter\_len}=\texttt{pfm\_len}$) must not overlap. So every co-occurring motif in
Experiment~2 is \emph{already} non-overlapping by construction, independent of the embedding
operator. In this model $\texttt{pfm\_len}=1$, so the rule reduces to ``the two motifs sit at
distinct positions'' --- exactly what occupancy and exclusivity measure. The two ``non-overlaps''
are one idea at two layers: the counter imposes it on discovered \emph{combinations}; the operator
(and the metric) act on the underlying \emph{activations}. The consequence is clarifying: the
operator is \emph{not} needed to make discovered co-occurrences non-overlapping --- that is
guaranteed downstream --- so its real lever is the cleanliness of the code itself, which is where
the trade-offs we measured live.

\paragraph{Separation and co-occurrence pull against each other.} Experiment~2 is the cautionary
half. The method finds co-occurring motifs by looking for filters that fire \emph{together}, and
separation is precisely the removal of that joint firing. Mild (softmax) separation only trims
discovery --- $14\to9$ significant pairs, $15\to11$ significant triplets --- but the hard variant we
tried made the code too sparse to run discovery at all. So the practical reading: \textbf{if the
goal is co-occurring motifs, keep separation mild}; a crisp one-filter-per-site code is the wrong
objective for that task.

\paragraph{Annealing is the natural next step.} Where separation did cost accuracy (softmax
$\alpha=100$), the model was trained sharp \emph{from scratch}. Ramping $\alpha$ up \emph{during}
training --- fit softly first, then harden --- should reach high separation for less of the tax.
The knob is already in place (\texttt{sparse\_unpool\_alpha}); only a per-epoch schedule is missing.

\paragraph{Caveats.} Single dataset, single seed, an MSE regression proxy for training (not the
method's full objective), and one inference layer ($L^\star=1$, $p=3$, $K=50$). The occupancy
numbers are stable across reruns, so the qualitative verdict is robust; the exact values are not.
